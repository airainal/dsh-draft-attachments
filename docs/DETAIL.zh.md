# 附件草稿保留

在 DSH 里给消息添加图片或文件后，如果发送前切换到别的会话再回来，文字还在，
附件却丢失。原因是浏览器保存的草稿快照只包含文本、引用、引用块和命令 token；
附件属于 Conversation 服务，会话作用域销毁时会被释放。

本插件增加按会话持久化的附件存档：

1. 替换输入框的 `conversation.input.attachments` 附件栏，渲染同样的草稿内容
   （图片缩略图、文件卡片、上传状态与重试），同时拿到浏览器端的 `File` 对象。
2. 附件栏变化时，把文件写入 IndexedDB，键为当前会话 ID。
3. 附件栏清空时删除存档，所以已发送的消息不会留下残留。
4. 重新打开会话时，通过输入框自己的 `onAddFiles` 入口恢复文件，图片配额、
   上传和发送仍是 DSH 原有逻辑。
5. 保留文档级拖入文件添加附件的能力。

## 不做什么

- 不修改 Host 会话记录、消息历史或文本草稿机制。
- 不复用旧的 Host 上传回执：恢复的文件会重新上传。
- 清除浏览器站点数据后无法恢复。

## 验证

1. 打开一个会话，输入文字并添加一张图片（以及一个文件）。
2. 切到另一个会话，再切回来。
3. 文字和两个附件都应恢复。发送该消息后存档应被删除，再切换一个来回也不再出现。
