# 附件草稿保留

DSH 会把每个会话的输入框草稿保存为文本、引用、引用块和命令 token。发送前
添加的图片和文件属于“浏览器端草稿附件”，会随会话作用域销毁而释放。于是切换
到其他会话再回来时，文字还在，附件却丢了。

本插件把未发送的附件保留在所属会话：

- 替换输入框的附件栏，从而拿到浏览器端的 `File` 对象。
- 按当前会话 ID 存入 IndexedDB；附件栏清空（已发送或逐个移除）时删除存档。
- 回到该会话时，通过输入框原有的添加附件路径重新加入，配额、上传和发送逻辑
  仍走 DSH 自己的实现。
- 保留文档级拖入文件添加附件的能力。

范围：只恢复离开会话时仍在输入框里的文件，不修改 Host 会话记录、已发送消息或
文本草稿逻辑。每个会话最多保留 24 个文件。

## 安装

在 **插件 → 添加插件** 中选择本目录，或让 agent 用 `plugin_manager`
`install_bundle` 安装。

## 限制

- 附件按浏览器源存在 IndexedDB 中，清除站点数据会丢失。
- 回到会话时会重新上传恢复的文件，不会复用旧草稿的 Host 上传回执。
